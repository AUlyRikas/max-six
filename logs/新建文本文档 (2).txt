逻辑辨析
"平二肖逆数3"的含义有两种理解：

理解	操作	例子（平二=马，马在生肖排第7位）
正数+3	平二肖往后数3位	马(7) → 羊(8)→猴(9)→鸡(10) = 鸡
逆数3	平二肖往前数3位	马(7) → 蛇(6)→龙(5)→兔(4) = 兔
如果"逆数3"是往前数，那等价于正数+9（往前3=往后9）。

快照里怎么写的不重要，关键是哪个逻辑杀对率高
两种都回测一遍，数据说话。我直接在 xiao1 的框架上加一个验证：

所以这里的平一到平六指的是号码,没有错对吧?
对。

平一到平六指的就是六个平码位置的号码，不是生肖。每个位置取该位置的数字做偏移运算，算出新号码对应的生肖作为杀肖候选。比如“平二【兔】-9 = 马”，意思是本期平二位置的号码对应的生肖是兔，把这个号码减9（或等价地加3）得到的新号码对应的生肖是马，就杀掉马。
你点出了关键问题——这个系统用的是号码偏移而不是生肖偏移，我搞混了。

正确的逻辑链
text
平二位置的号码 → 数字偏移（-9或+3）→ 新号码 → 查新号码对应的生肖 → 杀这个生肖
不是"平二生肖往后数3位"。

生肖每年轮换，同一个号码在不同年份对应不同生肖。所以号码偏移是对的——先偏移号码，再根据当年映射关系查生肖。这样偏移逻辑不受年份影响。

那你之前的动态位移杀肖回测已经验证过了
平二偏移的杀对率是 95.82%，这个数据很扎实。问题出在：九肖框架里用"杀平二逆数3"的方式不对。

快照里九肖的杀肖规则写的是"杀平二肖逆数3"，如果实现方式是"平二生肖往后数3位"而不是"平二号码-9后查生肖"，那就跟动态位移系统不是同一套逻辑，结果自然打折扣。

所以 xiao1.py 的结论需要修正
我测的"杀平二逆数3"是按生肖位移做的（平二生肖往后+3），杀对率92.02%。但你们的动态位移系统是按号码偏移做的，杀对率95.82%。两个逻辑不一样，差了近4个百分点。

下一步
xiao2.py 直接用动态位移系统的框架——平码号码偏移→查生肖→作为加分而非杀肖，注入九肖投票。这样：

保持和已验证系统一致（95.82%杀对率）

反过来用就是精选信号

六个位置独立偏移，各有最优参数

要我出 xiao2.py 按这个逻辑走吗？

是的,而且+3和-9其实是同一个对象,因为一轮就12个数或12个生肖,只是每年的岁数不一样
完全正确。模12的循环里，+3 ≡ -9，是同一个东西。但关键区别在于：

先偏移号码再查生肖 vs 直接偏移生肖，结果完全不同。

举个例子就清楚了：

年份	平二号码	平二生肖	号码-9后	号码+3后	结果生肖
2020	10	马	1	13	鼠(2020年1=鼠)
2021	10	蛇	1	13	猪(2021年1=猪)
2022	10	龙	1	13	狗(2022年1=狗)
同一个号码10，偏移后都是1，但每年1对应的生肖不一样。 如果直接偏移生肖（马往后3=鸡），不管年份永远是鸡——这跟动态位移系统验证的95.82%杀对率不是一套东西。

出 xiao2.py，按正确逻辑来：

六个平码位置，每个位置取号码

偏移 -11 ~ +11（等价于 ±1~±11 模49）

所得号码 → 查当年生肖 → 作为候选生肖

滚动回测，找每个位置的最优偏移方向

把高频命中的偏移生肖注入九肖投票加分

python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
xiao2.py — 平码号码偏移→生肖 信号验证
逻辑：6个平码位置，每个位置的号码做偏移(-11~+11模49)，
      所得号码→查当年生肖→统计命中下期特肖的频率
      滚动回测，找出每个位置的最优偏移方向
      将偏移生肖注入九肖投票，看能否突破76.02%
"""
import os
import sys
from collections import defaultdict, Counter

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
if BASE_DIR not in sys.path:
    sys.path.insert(0, BASE_DIR)

from shuju_loader import load_all_data

ZODIAC = ["鼠", "牛", "虎", "兔", "龙", "蛇", "马", "羊", "猴", "鸡", "狗", "猪"]
YEAR_SX = {2020: "鼠", 2021: "猪", 2022: "狗", 2023: "鸡", 2024: "猴", 2025: "羊", 2026: "马"}


def get_sx(num, year):
    """号码→生肖（按年份）"""
    start = YEAR_SX.get(year, "鼠")
    idx = (ZODIAC.index(start) - (num - 1)) % 12
    return ZODIAC[idx]


def extract(data):
    records = []
    for item in data:
        try:
            qs = str(item.get("expect", ""))
            oc = str(item.get("openCode", ""))
            year = int(qs[:4]) if len(qs) >= 4 else item.get("_year", 2020)
            if not qs or not oc: continue
            parts = oc.strip().split(",")
            if len(parts) != 7: continue
            nums = [int(p.strip()) for p in parts]
            records.append({
                "qishu": qs, "year": year,
                "te_num": nums[6],
                "te_sx": get_sx(nums[6], year),
                "ping_nums": nums[:6],  # 平一~平六 号码
                "ping_sx": [get_sx(n, year) for n in nums[:6]],
            })
        except: continue
    records.sort(key=lambda x: int(x["qishu"]))
    return records


def offset_num(num, offset):
    """号码偏移，模49，范围1~49"""
    result = (num - 1 + offset) % 49 + 1
    return result


def build_offset_stats(records, up_to, min_samples=30):
    """
    统计每个(位置, 偏移量)→所得生肖 命中下期特肖的频率
    返回: stats[pos][offset] = {"hit":次数, "total":次数, "sx_dist": Counter}
    """
    stats = [defaultdict(lambda: {"hit": 0, "total": 0, "sx_dist": Counter()}) for _ in range(6)]
    
    for i in range(up_to - 1):
        year = records[i]["year"]
        next_sx = records[i + 1]["te_sx"]
        
        for pos in range(6):
            num = records[i]["ping_nums"][pos]
            for offset in range(-11, 12):  # -11 ~ +11
                new_num = offset_num(num, offset)
                result_sx = get_sx(new_num, year)
                stats[pos][offset]["total"] += 1
                stats[pos][offset]["sx_dist"][result_sx] += 1
                if result_sx == next_sx:
                    stats[pos][offset]["hit"] += 1
    
    return stats


def top_offset_rules(stats, min_samples=30):
    """
    每个位置找最优偏移量及其命中率
    返回: best[pos] = (offset, hit_rate, top_sx_list)
    """
    best = []
    for pos in range(6):
        candidates = []
        for offset in range(-11, 12):
            data = stats[pos][offset]
            if data["total"] < min_samples:
                continue
            hit_rate = data["hit"] / data["total"] * 100
            # 取该偏移下命中次数最多的3个生肖
            top_sx = [sx for sx, _ in data["sx_dist"].most_common(3)]
            candidates.append({
                "offset": offset,
                "hit_rate": hit_rate,
                "hit": data["hit"],
                "total": data["total"],
                "top_sx": top_sx,
            })
        candidates.sort(key=lambda x: x["hit_rate"], reverse=True)
        best.append(candidates)
    return best


def predict_9xiao_base(records, up_to):
    """九肖基线（仅杀本期特肖版，76.02%）"""
    if up_to < 50:
        return ZODIAC[:9]
    
    ta = defaultdict(Counter)
    tb = defaultdict(lambda: defaultdict(float))
    tc = defaultdict(Counter)
    td = defaultdict(Counter)
    
    for i in range(up_to - 1):
        ta[records[i]["te_sx"]][records[i + 1]["te_sx"]] += 1
    for i in range(up_to - 1):
        dist = up_to - 1 - i
        w = 1.5 if dist <= 12 else (1.2 if dist <= 24 else 1.0)
        tb[records[i]["te_sx"]][records[i + 1]["te_sx"]] += w
    for i in range(up_to - 2):
        tc[(records[i]["te_sx"], records[i+1]["te_sx"])][records[i+2]["te_sx"]] += 1
    for i in range(up_to - 1):
        td[records[i]["te_num"]][records[i+1]["te_sx"]] += 1
    
    cur_sx = records[up_to - 1]["te_sx"]
    prev_sx = records[up_to - 2]["te_sx"] if up_to >= 2 else cur_sx
    cur_num = records[up_to - 1]["te_num"]
    
    scores = Counter()
    
    t = sum(ta[cur_sx].values())
    if t:
        for s, c in ta[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tb[cur_sx].values())
    if t:
        for s, c in tb[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tc[(prev_sx, cur_sx)].values())
    if t:
        for s, c in tc[(prev_sx, cur_sx)].items(): scores[s] += (c / t) * 0.20
    t = sum(td[cur_num].values())
    if t:
        for s, c in td[cur_num].items(): scores[s] += (c / t) * 0.20
    
    # 仅杀本期特肖
    if cur_sx in scores:
        del scores[cur_sx]
    
    top9 = [s for s, _ in scores.most_common(9)]
    if len(top9) < 9:
        freq = Counter(r["te_sx"] for r in records[:up_to])
        for s, _ in freq.most_common(12):
            if s not in top9:
                top9.append(s)
            if len(top9) >= 9:
                break
    return top9[:9]


def predict_9xiao_enhanced(records, up_to, best_rules, bonus_weight=0.08):
    """
    增强版九肖：基线投票 + 偏移生肖加权
    best_rules: top_offset_rules返回的结果
    bonus_weight: 偏移信号的加分权重
    """
    if up_to < 200:
        return predict_9xiao_base(records, up_to)
    
    ta = defaultdict(Counter)
    tb = defaultdict(lambda: defaultdict(float))
    tc = defaultdict(Counter)
    td = defaultdict(Counter)
    
    for i in range(up_to - 1):
        ta[records[i]["te_sx"]][records[i + 1]["te_sx"]] += 1
    for i in range(up_to - 1):
        dist = up_to - 1 - i
        w = 1.5 if dist <= 12 else (1.2 if dist <= 24 else 1.0)
        tb[records[i]["te_sx"]][records[i + 1]["te_sx"]] += w
    for i in range(up_to - 2):
        tc[(records[i]["te_sx"], records[i+1]["te_sx"])][records[i+2]["te_sx"]] += 1
    for i in range(up_to - 1):
        td[records[i]["te_num"]][records[i+1]["te_sx"]] += 1
    
    cur_sx = records[up_to - 1]["te_sx"]
    prev_sx = records[up_to - 2]["te_sx"] if up_to >= 2 else cur_sx
    cur_num = records[up_to - 1]["te_num"]
    cur_year = records[up_to - 1]["year"]
    
    scores = Counter()
    
    t = sum(ta[cur_sx].values())
    if t:
        for s, c in ta[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tb[cur_sx].values())
    if t:
        for s, c in tb[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tc[(prev_sx, cur_sx)].values())
    if t:
        for s, c in tc[(prev_sx, cur_sx)].items(): scores[s] += (c / t) * 0.20
    t = sum(td[cur_num].values())
    if t:
        for s, c in td[cur_num].items(): scores[s] += (c / t) * 0.20
    
    # 偏移加分：每个位置取Top1偏移，触发对应生肖加权
    for pos in range(6):
        if not best_rules[pos]:
            continue
        best_rule = best_rules[pos][0]  # 最优偏移
        offset = best_rule["offset"]
        num = records[up_to - 1]["ping_nums"][pos]
        new_num = offset_num(num, offset)
        bonus_sx = get_sx(new_num, cur_year)
        hit_rate = best_rule["hit_rate"] / 100
        scores[bonus_sx] += hit_rate * bonus_weight
    
    # 仅杀本期特肖
    if cur_sx in scores:
        del scores[cur_sx]
    
    top9 = [s for s, _ in scores.most_common(9)]
    if len(top9) < 9:
        freq = Counter(r["te_sx"] for r in records[:up_to])
        for s, _ in freq.most_common(12):
            if s not in top9:
                top9.append(s)
            if len(top9) >= 9:
                break
    return top9[:9]


def main():
    print("xiao2.py — 平码号码偏移→生肖 信号验证")
    print("=" * 60)
    
    data = load_all_data(auto_update=False)
    records = extract(data)
    print(f"记录数: {len(records)}")
    
    # ====== 全局偏移统计 ======
    print(f"\n各位置最优偏移方向 (全局统计, 样本≥30):")
    print("-" * 70)
    print(f"{'位置':<6} {'最优偏移':<8} {'命中率':<8} {'样本':<10} {'高频生肖'}")
    print("-" * 70)
    
    stats_all = build_offset_stats(records, len(records))
    best_all = top_offset_rules(stats_all)
    
    for pos in range(6):
        if best_all[pos]:
            r = best_all[pos][0]
            print(f"  平{pos+1}   | {r['offset']:+3d}     | {r['hit_rate']:5.2f}%  | {r['hit']}/{r['total']:<6} | {r['top_sx']}")
    
    # ====== 滚动回测：纯偏移信号 ======
    print(f"\n纯偏移信号命中率 (每期各位置取最优偏移触发生肖Top6):")
    
    hits_pure, total_pure = 0, 0
    for idx in range(200, len(records)):
        stats_rolling = build_offset_stats(records, idx)
        best_rolling = top_offset_rules(stats_rolling)
        
        bonus_sx_set = set()
        for pos in range(6):
            if best_rolling[pos]:
                offset = best_rolling[pos][0]["offset"]
                num = records[idx - 1]["ping_nums"][pos]
                new_num = offset_num(num, records[idx - 1]["year"])
                bonus_sx_set.add(get_sx(new_num, records[idx - 1]["year"]))
        
        total_pure += 1
        if records[idx]["te_sx"] in bonus_sx_set:
            hits_pure += 1
    
    print(f"  偏移信号覆盖生肖数: ~{hits_pure/total_pure*len(bonus_sx_set) if total_pure else 0:.1f}")
    print(f"  命中率: {hits_pure/total_pure*100:.2f}% ({hits_pure}/{total_pure})")
    
    # ====== 增强版九肖回测 ======
    print(f"\n九肖增强回测 (偏移加权注入):")
    
    for bonus_w in [0.05, 0.08, 0.10, 0.12, 0.15]:
        hits, total = 0, 0
        for idx in range(200, len(records)):
            stats_rolling = build_offset_stats(records, idx)
            best_rolling = top_offset_rules(stats_rolling)
            pred = predict_9xiao_enhanced(records, idx, best_rolling, bonus_weight=bonus_w)
            total += 1
            if records[idx]["te_sx"] in pred:
                hits += 1
        rate = hits / total * 100
        marker = " ★" if rate > 76.02 else ""
        print(f"  bonus_w={bonus_w:.2f}: {rate:.2f}% ({hits}/{total}){marker}")
    
    # 基线对比
    print(f"\n  基线(仅杀本期特肖): 76.02%")
    
    # ====== 偏移命中分布（哪些位置更有效） ======
    print(f"\n各位置独立命中率 (取最优偏移):")
    for pos in range(6):
        hits, total = 0, 0
        for idx in range(200, len(records)):
            stats_rolling = build_offset_stats(records, idx)
            best_rolling = top_offset_rules(stats_rolling)
            if best_rolling[pos]:
                offset = best_rolling[pos][0]["offset"]
                num = records[idx - 1]["ping_nums"][pos]
                new_num = offset_num(num, records[idx - 1]["year"])
                result_sx = get_sx(new_num, records[idx - 1]["year"])
                total += 1
                if records[idx]["te_sx"] == result_sx:
                    hits += 1
        print(f"  平{pos+1}: {hits/total*100:.2f}% ({hits}/{total})")
    
    print(f"\n===== xiao2.py 完成 =====")


if __name__ == "__main__":
    main()

python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
xiao3.py — 修正杀平二逆数3的实现：号码偏移代替生肖位移
对比：
  A. 现版：平二生肖往后+3 → 杀掉
  B. 修正：平二号码-9(模49) → 查当年生肖 → 杀掉
看修正后九肖命中率是否提升
"""
import os
import sys
from collections import defaultdict, Counter

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
if BASE_DIR not in sys.path:
    sys.path.insert(0, BASE_DIR)

from shuju_loader import load_all_data

ZODIAC = ["鼠", "牛", "虎", "兔", "龙", "蛇", "马", "羊", "猴", "鸡", "狗", "猪"]
YEAR_SX = {2020: "鼠", 2021: "猪", 2022: "狗", 2023: "鸡", 2024: "猴", 2025: "羊", 2026: "马"}


def get_sx(num, year):
    start = YEAR_SX.get(year, "鼠")
    idx = (ZODIAC.index(start) - (num - 1)) % 12
    return ZODIAC[idx]


def extract(data):
    records = []
    for item in data:
        try:
            qs = str(item.get("expect", ""))
            oc = str(item.get("openCode", ""))
            year = int(qs[:4]) if len(qs) >= 4 else item.get("_year", 2020)
            if not qs or not oc: continue
            parts = oc.strip().split(",")
            if len(parts) != 7: continue
            nums = [int(p.strip()) for p in parts]
            records.append({
                "qishu": qs, "year": year,
                "te_num": nums[6], "te_sx": get_sx(nums[6], year),
                "ping_nums": nums[:6],
                "ping_sx": [get_sx(n, year) for n in nums[:6]],
            })
        except: continue
    records.sort(key=lambda x: int(x["qishu"]))
    return records


def offset_num(num, offset):
    return (num - 1 + offset) % 49 + 1


def predict_9xiao(records, up_to, p2_method="sx_shift"):
    """
    p2_method:
      "sx_shift"  = 现版：平二生肖往后+3
      "num_offset" = 修正：平二号码-9 → 查当年生肖
    """
    if up_to < 50:
        return ZODIAC[:9]

    ta = defaultdict(Counter)
    tb = defaultdict(lambda: defaultdict(float))
    tc = defaultdict(Counter)
    td = defaultdict(Counter)

    for i in range(up_to - 1):
        ta[records[i]["te_sx"]][records[i + 1]["te_sx"]] += 1
    for i in range(up_to - 1):
        dist = up_to - 1 - i
        w = 1.5 if dist <= 12 else (1.2 if dist <= 24 else 1.0)
        tb[records[i]["te_sx"]][records[i + 1]["te_sx"]] += w
    for i in range(up_to - 2):
        tc[(records[i]["te_sx"], records[i + 1]["te_sx"])][records[i + 2]["te_sx"]] += 1
    for i in range(up_to - 1):
        td[records[i]["te_num"]][records[i + 1]["te_sx"]] += 1

    cur_sx = records[up_to - 1]["te_sx"]
    prev_sx = records[up_to - 2]["te_sx"] if up_to >= 2 else cur_sx
    cur_num = records[up_to - 1]["te_num"]
    cur_year = records[up_to - 1]["year"]

    scores = Counter()

    t = sum(ta[cur_sx].values())
    if t:
        for s, c in ta[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tb[cur_sx].values())
    if t:
        for s, c in tb[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tc[(prev_sx, cur_sx)].values())
    if t:
        for s, c in tc[(prev_sx, cur_sx)].items(): scores[s] += (c / t) * 0.20
    t = sum(td[cur_num].values())
    if t:
        for s, c in td[cur_num].items(): scores[s] += (c / t) * 0.20

    # 杀本期特肖
    if cur_sx in scores:
        del scores[cur_sx]

    # 杀平二逆数3
    if len(records[up_to - 1]["ping_nums"]) >= 2:
        if p2_method == "sx_shift":
            # 现版：平二生肖往后+3
            p2_sx = records[up_to - 1]["ping_sx"][1]
            kill_sx = ZODIAC[(ZODIAC.index(p2_sx) + 3) % 12]
        else:
            # 修正：平二号码-9 → 查当年生肖
            p2_num = records[up_to - 1]["ping_nums"][1]
            new_num = offset_num(p2_num, -9)
            kill_sx = get_sx(new_num, cur_year)

        if kill_sx in scores:
            del scores[kill_sx]

    top9 = [s for s, _ in scores.most_common(9)]
    if len(top9) < 9:
        freq = Counter(r["te_sx"] for r in records[:up_to])
        for s, _ in freq.most_common(12):
            if s not in top9:
                top9.append(s)
            if len(top9) >= 9:
                break
    return top9[:9]


def backtest(records, p2_method, label):
    hits, total = 0, 0
    for idx in range(200, len(records)):
        pred = predict_9xiao(records, idx, p2_method=p2_method)
        if records[idx]["te_sx"] in pred:
            hits += 1
        total += 1
    return hits / total * 100, hits, total


def main():
    print("xiao3.py — 修正平二逆数3实现：号码偏移 vs 生肖位移")
    print("=" * 60)

    data = load_all_data(auto_update=False)
    records = extract(data)
    print(f"记录数: {len(records)}")

    # 对比
    print(f"\n{'方法':<20} {'命中率':<10} {'命中/总数':<12} {'vs现版'}")
    print("-" * 55)

    r_old, h_old, t_old = backtest(records, "sx_shift", "现版")
    r_new, h_new, t_new = backtest(records, "num_offset", "修正版")

    print(f"  现版(生肖位移)        {r_old:.2f}%     {h_old}/{t_old}")
    print(f"  修正(号码偏移)        {r_new:.2f}%     {h_new}/{t_new}       {r_new-r_old:+.2f}%")

    # 两种方法的独立杀对率
    print(f"\n平二逆数3 独立杀对率对比:")
    for method, label in [("sx_shift", "生肖位移+3"), ("num_offset", "号码-9查生肖")]:
        kills, correct = 0, 0
        for idx in range(200, len(records)):
            if len(records[idx - 1]["ping_nums"]) < 2:
                continue
            if method == "sx_shift":
                p2_sx = records[idx - 1]["ping_sx"][1]
                target = ZODIAC[(ZODIAC.index(p2_sx) + 3) % 12]
            else:
                p2_num = records[idx - 1]["ping_nums"][1]
                new_num = offset_num(p2_num, -9)
                target = get_sx(new_num, records[idx - 1]["year"])
            kills += 1
            if records[idx]["te_sx"] != target:
                correct += 1
        rate = correct / kills * 100 if kills else 0
        print(f"  {label}: 杀对率 {rate:.2f}% ({correct}/{kills})")

    # 看两版实际杀的是不是同一个生肖
    print(f"\n两版杀同一生肖的比例:")
    same_count = 0
    for idx in range(200, len(records)):
        if len(records[idx - 1]["ping_sx"]) < 2:
            continue
        p2_sx = records[idx - 1]["ping_sx"][1]
        sx_kill = ZODIAC[(ZODIAC.index(p2_sx) + 3) % 12]
        p2_num = records[idx - 1]["ping_nums"][1]
        num_kill = get_sx(offset_num(p2_num, -9), records[idx - 1]["year"])
        if sx_kill == num_kill:
            same_count += 1
    print(f"  杀同一生肖: {same_count}/{1981} = {same_count/1981*100:.1f}%")

    print(f"\n===== xiao3.py 完成 =====")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
xiao3b.py — 平二逆数3 全维度对比
四个维度：
  1. 生肖位移 +3（现版）
  2. 生肖位移 -9（等价+3，但方向不同）
  3. 号码位移 +3（号码+3后查生肖）
  4. 号码位移 -9（号码-9后查生肖）
每个维度：独立杀对率 + 注入九肖后的命中率
"""
import os
import sys
from collections import defaultdict, Counter

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
if BASE_DIR not in sys.path:
    sys.path.insert(0, BASE_DIR)

from shuju_loader import load_all_data

ZODIAC = ["鼠", "牛", "虎", "兔", "龙", "蛇", "马", "羊", "猴", "鸡", "狗", "猪"]
YEAR_SX = {2020: "鼠", 2021: "猪", 2022: "狗", 2023: "鸡", 2024: "猴", 2025: "羊", 2026: "马"}


def get_sx(num, year):
    start = YEAR_SX.get(year, "鼠")
    idx = (ZODIAC.index(start) - (num - 1)) % 12
    return ZODIAC[idx]


def offset_num(num, offset):
    return (num - 1 + offset) % 49 + 1


def extract(data):
    records = []
    for item in data:
        try:
            qs = str(item.get("expect", ""))
            oc = str(item.get("openCode", ""))
            year = int(qs[:4]) if len(qs) >= 4 else item.get("_year", 2020)
            if not qs or not oc: continue
            parts = oc.strip().split(",")
            if len(parts) != 7: continue
            nums = [int(p.strip()) for p in parts]
            records.append({
                "qishu": qs, "year": year,
                "te_num": nums[6], "te_sx": get_sx(nums[6], year),
                "ping_nums": nums[:6],
                "ping_sx": [get_sx(n, year) for n in nums[:6]],
            })
        except: continue
    records.sort(key=lambda x: int(x["qishu"]))
    return records


def get_kill_target(records, idx, method):
    """根据方法获取杀肖目标"""
    if len(records[idx]["ping_sx"]) < 2:
        return None
    p2_num = records[idx]["ping_nums"][1]
    p2_sx = records[idx]["ping_sx"][1]
    year = records[idx]["year"]

    if method == "sx+3":
        return ZODIAC[(ZODIAC.index(p2_sx) + 3) % 12]
    elif method == "sx-9":
        return ZODIAC[(ZODIAC.index(p2_sx) - 9) % 12]
    elif method == "num+3":
        return get_sx(offset_num(p2_num, +3), year)
    elif method == "num-9":
        return get_sx(offset_num(p2_num, -9), year)
    return None


def predict_9xiao(records, up_to, p2_method):
    """九肖预测，p2_method为杀肖方法"""
    if up_to < 50:
        return ZODIAC[:9]

    ta = defaultdict(Counter)
    tb = defaultdict(lambda: defaultdict(float))
    tc = defaultdict(Counter)
    td = defaultdict(Counter)

    for i in range(up_to - 1):
        ta[records[i]["te_sx"]][records[i + 1]["te_sx"]] += 1
    for i in range(up_to - 1):
        dist = up_to - 1 - i
        w = 1.5 if dist <= 12 else (1.2 if dist <= 24 else 1.0)
        tb[records[i]["te_sx"]][records[i + 1]["te_sx"]] += w
    for i in range(up_to - 2):
        tc[(records[i]["te_sx"], records[i + 1]["te_sx"])][records[i + 2]["te_sx"]] += 1
    for i in range(up_to - 1):
        td[records[i]["te_num"]][records[i + 1]["te_sx"]] += 1

    cur_sx = records[up_to - 1]["te_sx"]
    prev_sx = records[up_to - 2]["te_sx"] if up_to >= 2 else cur_sx
    cur_num = records[up_to - 1]["te_num"]

    scores = Counter()

    t = sum(ta[cur_sx].values())
    if t:
        for s, c in ta[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tb[cur_sx].values())
    if t:
        for s, c in tb[cur_sx].items(): scores[s] += (c / t) * 0.30
    t = sum(tc[(prev_sx, cur_sx)].values())
    if t:
        for s, c in tc[(prev_sx, cur_sx)].items(): scores[s] += (c / t) * 0.20
    t = sum(td[cur_num].values())
    if t:
        for s, c in td[cur_num].items(): scores[s] += (c / t) * 0.20

    # 杀本期特肖
    if cur_sx in scores:
        del scores[cur_sx]

    # 杀平二逆数3
    if p2_method != "none":
        kill_target = get_kill_target(records, up_to - 1, p2_method)
        if kill_target and kill_target in scores:
            del scores[kill_target]

    top9 = [s for s, _ in scores.most_common(9)]
    if len(top9) < 9:
        freq = Counter(r["te_sx"] for r in records[:up_to])
        for s, _ in freq.most_common(12):
            if s not in top9:
                top9.append(s)
            if len(top9) >= 9:
                break
    return top9[:9]


def main():

        rate = correct / kills * 100

    # 九肖命中率

        print(f"  {m:<12}  {kill_rates[m]:5.2f}%       {hits/total*100:5.2f}%")

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
xiao4.py — 号码±偏移→中心→±4窗口→九肖
逻辑：
  本期7个号码(平1~平6+特码)，每个号码做偏移 ±0~±12 得到中心号码
  中心号码 ±4 得到9个号码 → 转为生肖 → 检查是否包含下期特肖
  统计每个(位置, 偏移量)的命中率，找出最优方案
"""
import os
import sys
from collections import defaultdict, Counter

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
if BASE_DIR not in sys.path:
    sys.path.insert(0, BASE_DIR)

from shuju_loader import load_all_data

ZODIAC = ["鼠", "牛", "虎", "兔", "龙", "蛇", "马", "羊", "猴", "鸡", "狗", "猪"]
YEAR_SX = {2020: "鼠", 2021: "猪", 2022: "狗", 2023: "鸡", 2024: "猴", 2025: "羊", 2026: "马"}


def get_sx(num, year):
    start = YEAR_SX.get(year, "鼠")
    idx = (ZODIAC.index(start) - (num - 1)) % 12
    return ZODIAC[idx]


def offset_num(num, offset):
    """号码偏移，模49，1~49"""
    return (num - 1 + offset) % 49 + 1


def extract(data):
    records = []
    for item in data:
        try:
            qs = str(item.get("expect", ""))
            oc = str(item.get("openCode", ""))
            year = int(qs[:4]) if len(qs) >= 4 else item.get("_year", 2020)
            if not qs or not oc: continue
            parts = oc.strip().split(",")
            if len(parts) != 7: continue
            nums = [int(p.strip()) for p in parts]
            records.append({
                "qishu": qs, "year": year,
                "te_sx": get_sx(nums[6], year),
                "all_nums": nums,  # 平1~平6 + 特码 = 7个
            })
        except: continue
    records.sort(key=lambda x: int(x["qishu"]))
    return records


def nums_to_sx_set(nums, year):
    """号码列表→生肖集合"""
    return {get_sx(n, year) for n in nums}


def generate_9xiao(base_num, offset, window=4, year=2026):
    """
    base_num ± offset → 中心号码
    中心号码 ± window → 9个号码
    返回：9个生肖的集合
    """
    center = offset_num(base_num, offset)
    candidates = []
    for w in range(-window, window + 1):
        candidates.append(offset_num(center, w))
    return nums_to_sx_set(candidates, year)

    # ====== 每个位置的最优偏移 ======
    print(f"\n各位置最优偏移:")

    print("-" * 40)

    for pos in range(7):

    # ====== 全位置取最优偏移，综合命中率 ======
    print(f"\n各位置独立最优偏移 → 合并九肖 (各位置取最优偏移生成的9肖取并集):")
    total_hits = 0
    total_count = 0
    total_sx_count = 0

    for idx in range(min_hist, len(records)):
        year = records[idx - 1]["year"]
        all_sx = set()
        for pos in range(7):
            base_num = records[idx - 1]["all_nums"][pos]
            best_offset = max(offset_range, key=lambda o: global_results[(pos, o)])
            sx9 = generate_9xiao(base_num, best_offset, window=4, year=year)
            all_sx.update(sx9)
        total_count += 1
        total_sx_count += len(all_sx)
        if records[idx]["te_sx"] in all_sx:
            total_hits += 1

    merge_rate = total_hits / total_count * 100
    avg_sx = total_sx_count / total_count
    print(f"  平均覆盖生肖: {avg_sx:.1f}/12")
    print(f"  命中率: {merge_rate:.2f}% ({total_hits}/{total_count})")

    # ====== 偏移=0时的基线 ======
    print(f"\n偏移=0时的命中率 (即本期号码±4窗口):")
    for pos in range(7):
        rate = global_results[(pos, 0)]
        print(f"  {pos_names[pos]:<4}: {rate:.2f}%")

    # ====== 按偏移量汇总（所有位置平均） ======
    print(f"\n各偏移量所有位置平均命中率 Top5:")
    offset_avg = []
    for offset in offset_range:
        avg = sum(global_results[(pos, offset)] for pos in range(7)) / 7
        offset_avg.append((offset, avg))
    offset_avg.sort(key=lambda x: x[1], reverse=True)
    for offset, avg in offset_avg[:5]:
        print(f"  偏移{offset:+3d}: 平均{avg:.2f}%")

    print(f"\n===== xiao4.py 完成 =====")


if __name__ == "__main__":

python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
xiao5.py — 全位置+特码 双条件规则扫描
输出：位置 | 偏移 | 平码生肖/特肖 | 所得生肖 | 样本量 | 命中率
六个平码位置 + 特码位置，偏移 -11 ~ +11，样本≥30
"""
import os
import sys
from collections import defaultdict, Counter

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
if BASE_DIR not in sys.path:
    sys.path.insert(0, BASE_DIR)

from shuju_loader import load_all_data

ZODIAC = ["鼠", "牛", "虎", "兔", "龙", "蛇", "马", "羊", "猴", "鸡", "狗", "猪"]
YEAR_SX = {2020: "鼠", 2021: "猪", 2022: "狗", 2023: "鸡", 2024: "猴", 2025: "羊", 2026: "马"}


def get_sx(num, year):
    start = YEAR_SX.get(year, "鼠")
    idx = (ZODIAC.index(start) - (num - 1)) % 12
    return ZODIAC[idx]


def offset_num(num, offset):
    return (num - 1 + offset) % 49 + 1


def extract(data):
    records = []
    for item in data:
        try:
            qs = str(item.get("expect", ""))
            oc = str(item.get("openCode", ""))
            year = int(qs[:4]) if len(qs) >= 4 else item.get("_year", 2020)
            if not qs or not oc: continue
            parts = oc.strip().split(",")
            if len(parts) != 7: continue
            nums = [int(p.strip()) for p in parts]
            records.append({
                "qishu": qs, "year": year,
                "te_num": nums[6], "te_sx": get_sx(nums[6], year),
                "ping_nums": nums[:6],
                "ping_sx": [get_sx(n, year) for n in nums[:6]],
            })
        except: continue
    records.sort(key=lambda x: int(x["qishu"]))
    return records


def scan_all(records, min_samples=30):
    """
    扫描所有(位置, 偏移, 平码生肖)组合的杀对率
    位置: 0~6 (平一~平六 + 特码)
    """
    pos_names = ["平一", "平二", "平三", "平四", "平五", "平六", "特码"]
    all_rules = []

    for pos in range(7):
        # 统计每种规则
        stats = defaultdict(lambda: {"kill": 0, "total": 0, "result_sx": None})

        for i in range(len(records) - 1):
            year = records[i]["year"]
            if pos < 6:
                num = records[i]["ping_nums"][pos]
                sx = records[i]["ping_sx"][pos]
            else:
                num = records[i]["te_num"]
                sx = records[i]["te_sx"]

            next_sx = records[i + 1]["te_sx"]

            for offset in range(-11, 12):
                new_num = offset_num(num, offset)
                result_sx = get_sx(new_num, year)
                key = (offset, sx)
                stats[key]["total"] += 1
                stats[key]["result_sx"] = result_sx
                if next_sx != result_sx:
                    stats[key]["kill"] += 1

        # 筛选样本≥min_samples的规则
        for (offset, sx), data in stats.items():
            if data["total"] >= min_samples:
                kill_rate = data["kill"] / data["total"] * 100
                all_rules.append({
                    "pos": pos_names[pos],
                    "offset": offset,
                    "ping_sx": sx,
                    "result_sx": data["result_sx"],
                    "samples": data["total"],
                    "kill_rate": kill_rate,
                })

    # 按命中率降序
    all_rules.sort(key=lambda x: x["kill_rate"], reverse=True)
    return all_rules


def main():
    print("xiao5.py — 全位置双条件规则扫描")
    print("正在加载数据...")

    data = load_all_data(auto_update=False)
    records = extract(data)
    print(f"记录数: {len(records)}")

    print("正在扫描规则...")
    rules = scan_all(records, min_samples=30)

    # 输出到文件
    output_path = os.path.join(BASE_DIR, "dongtai_rules_full.txt")
    with open(output_path, "w", encoding="utf-8") as f:
        f.write(f"{'位置':<6} {'偏移':<6} {'平码生肖':<8} {'所得生肖':<8} {'样本量':<8} {'杀对率':<10}\n")
        f.write("-" * 55 + "\n")
        for r in rules:
            f.write(f"{r['pos']:<6} {r['offset']:+4d}   {r['ping_sx']:<8} {r['result_sx']:<8} {r['samples']:<8} {r['kill_rate']:.2f}%\n")

    print(f"\n规则总数: {len(rules)}")
    print(f"已保存到: {output_path}")

    # 各位置Top5预览
    print(f"\n各位置 Top5 规则预览:")
    print(f"{'位置':<6} {'偏移':<6} {'平码生肖':<8} {'所得生肖':<8} {'样本':<6} {'杀对率'}")
    print("-" * 55)
    pos_names = ["平一", "平二", "平三", "平四", "平五", "平六", "特码"]
    for pos_name in pos_names:
        pos_rules = [r for r in rules if r["pos"] == pos_name]
        print(f"\n  [{pos_name}] 共{len(pos_rules)}条:")
        for r in pos_rules[:5]:
            print(f"    {r['offset']:+4d}   {r['ping_sx']:<8} → {r['result_sx']:<8} {r['samples']:<6} {r['kill_rate']:.2f}%")

    print(f"\n===== xiao5.py 完成 =====")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
xiao6.py — 特码位置 + 全位置 双维度规则画像
输出：位置 | 最佳偏移 | 全局命中率 | 极值命中率 | 触发条件 | 所得生肖 | 样本
"""
import os
import sys
from collections import defaultdict, Counter

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
if BASE_DIR not in sys.path:
    sys.path.insert(0, BASE_DIR)

from shuju_loader import load_all_data

ZODIAC = ["鼠", "牛", "虎", "兔", "龙", "蛇", "马", "羊", "猴", "鸡", "狗", "猪"]
YEAR_SX = {2020: "鼠", 2021: "猪", 2022: "狗", 2023: "鸡", 2024: "猴", 2025: "羊", 2026: "马"}


def get_sx(num, year):
    start = YEAR_SX.get(year, "鼠")
    idx = (ZODIAC.index(start) - (num - 1)) % 12
    return ZODIAC[idx]


def offset_num(num, offset):
    return (num - 1 + offset) % 49 + 1


def extract(data):
    records = []
    for item in data:
        try:
            qs = str(item.get("expect", ""))
            oc = str(item.get("openCode", ""))
            year = int(qs[:4]) if len(qs) >= 4 else item.get("_year", 2020)
            if not qs or not oc: continue
            parts = oc.strip().split(",")
            if len(parts) != 7: continue
            nums = [int(p.strip()) for p in parts]
            records.append({
                "qishu": qs, "year": year,
                "te_num": nums[6], "te_sx": get_sx(nums[6], year),
                "ping_nums": nums[:6],
                "ping_sx": [get_sx(n, year) for n in nums[:6]],
            })
        except: continue
    records.sort(key=lambda x: int(x["qishu"]))
    return records


def scan_position(records, pos, min_samples=30):
    """
    扫描单个位置：
    1. 找到全局最优偏移
    2. 在该偏移下找到极值命中率的条件
    """
    pos_names = ["平一", "平二", "平三", "平四", "平五", "平六", "特码"]

    # 全局：每个偏移的命中率
    offset_stats = defaultdict(lambda: {"kill": 0, "total": 0})
    # 双条件：每个(偏移, 生肖)的命中率
    detail_stats = defaultdict(lambda: {"kill": 0, "total": 0, "result_sx": None})

    for i in range(len(records) - 1):
        year = records[i]["year"]
        if pos < 6:
            num = records[i]["ping_nums"][pos]
            sx = records[i]["ping_sx"][pos]
        else:
            num = records[i]["te_num"]
            sx = records[i]["te_sx"]
        next_sx = records[i + 1]["te_sx"]

        for offset in range(-11, 12):
            new_num = offset_num(num, offset)
            result_sx = get_sx(new_num, year)
            offset_stats[offset]["total"] += 1
            if next_sx != result_sx:
                offset_stats[offset]["kill"] += 1

            key = (offset, sx)
            detail_stats[key]["total"] += 1
            detail_stats[key]["result_sx"] = result_sx
            if next_sx != result_sx:
                detail_stats[key]["kill"] += 1

    # 找全局最优偏移
    best_offset = None
    best_global_rate = 0
    for offset, data in offset_stats.items():
        if data["total"] >= 63:  # 样本≥63（与图片一致）
            rate = data["kill"] / data["total"] * 100
            if rate > best_global_rate:
                best_global_rate = rate
                best_offset = offset

    # 在该最优偏移下找极值条件
    best_detail = None
    best_detail_rate = 0
    for (offset, sx), data in detail_stats.items():
        if offset == best_offset and data["total"] >= min_samples:
            rate = data["kill"] / data["total"] * 100
            if rate > best_detail_rate:
                best_detail_rate = rate
                best_detail = {
                    "sx": sx,
                    "result_sx": data["result_sx"],
                    "samples": data["total"],
                    "rate": rate,
                }

    return {
        "pos": pos_names[pos],
        "best_offset": best_offset,
        "global_rate": best_global_rate,
        "detail": best_detail,
    }


def main():
    print("xiao6.py — 全位置规则画像")
    print("正在加载数据...")

    data = load_all_data(auto_update=False)
    records = extract(data)
    print(f"记录数: {len(records)}")

    results = []
    for pos in range(7):
        r = scan_position(records, pos, min_samples=30)
        results.append(r)

    # 输出表格
    print(f"\n{'位置':<6} {'最佳偏移':<8} {'全局命中率':<10} {'极值命中率':<10} {'触发条件':<22} {'所得生肖':<8} {'样本':<6}")
    print("-" * 80)
    for r in results:
        d = r["detail"]
        if d:
            cond = f"{r['pos']}【{d['sx']}】{r['best_offset']:+d}"
            print(f"{r['pos']:<6} {r['best_offset']:+4d}     {r['global_rate']:.2f}%       {d['rate']:.2f}%         {cond:<20}  {d['result_sx']:<8} {d['samples']}<6")
        else:
            print(f"{r['pos']:<6} {r['best_offset']:+4d}     {r['global_rate']:.2f}%       -           -                      -        -")

    # 保存
    output_path = os.path.join(BASE_DIR, "rules_portrait.txt")
    with open(output_path, "w", encoding="utf-8") as f:
        f.write(f"{'位置':<6} {'最佳偏移':<8} {'全局命中率':<10} {'极值命中率':<10} {'触发条件':<22} {'所得生肖':<8} {'样本':<6}\n")
        f.write("-" * 80 + "\n")
        for r in results:
            d = r["detail"]
            if d:
                cond = f"{r['pos']}【{d['sx']}】{r['best_offset']:+d}"
                f.write(f"{r['pos']:<6} {r['best_offset']:+4d}     {r['global_rate']:.2f}%       {d['rate']:.2f}%         {cond:<20}  {d['result_sx']:<8} {d['samples']}\n")
    print(f"\n已保存: {output_path}")

    print(f"\n===== xiao6.py 完成 =====")


if __name__ == "__main__":
    main()

def load_unique_data():

def build_all_dual_rules(data):
    stats1 = defaultdict(lambda: defaultdict(int))
    stats2 = defaultdict(lambda: defaultdict(int))
    stats3 = defaultdict(lambda: defaultdict(int))
    stats4 = defaultdict(lambda: defaultdict(int))
    for i in range(len(data) - 1):
        curr, nxt = data[i], data[i+1]
        codes = curr.get('openCode','').split(',')
        nxt_codes = nxt.get('openCode','').split(',')
        if len(codes) < 7 or len(nxt_codes) < 7: continue
        curr_year = int(curr.get('openTime','')[:4]) if curr.get('openTime') else 2026
        nxt_te_sx = get_shengxiao_by_suima(int(nxt_codes[-1]),
                                           int(nxt.get('openTime','')[:4]) if nxt.get('openTime') else curr_year)
        cur_tail = int(codes[-1]) % 10
        cur_te_sx = get_shengxiao_by_suima(int(codes[-1]), curr_year)
        for idx, pos in enumerate(POS_NAMES):
            ping_num = int(codes[idx])
            ping_sx = get_shengxiao_by_suima(ping_num, curr_year)
            ping_tail = ping_num % 10
            stats1[(pos, ping_sx, cur_tail)][nxt_te_sx] += 1
            stats2[(cur_te_sx, pos, ping_tail)][nxt_te_sx] += 1
            stats3[(pos, ping_sx, cur_te_sx)][nxt_te_sx] += 1
            stats4[(pos, ping_tail, cur_tail)][nxt_te_sx] += 1

    def make_rules(stats_dict, rule_type, cond_func, min_samples=30):
        rules = []
        for key, count_map in stats_dict.items():
            total = sum(count_map.values())
            if total < min_samples: continue
            never = [z for z in ALL_ZODIAC if count_map.get(z, 0) == 0]
            top9 = [z for z, _ in sorted(count_map.items(), key=lambda x: x[1], reverse=True)[:9]]
            top9_hit = sum(count_map.get(z, 0) for z in top9)
            rules.append({

                '条件': cond_func(key),
                '杀肖候选': never,
                '大范围9肖': top9,
                '大范围命中率': round(top9_hit / total * 100, 2),
                '样本量': total
            })
        return rules

    rules = []
    rules += make_rules(stats1, '平肖+特尾', lambda k: f"{k[0]}【{k[1]}】+特尾【{k[2]}】")

            if match_count == 2: matched.append(rule)

def get_related_kill(all_rules, cur_codes, cur_year):
    matched, related = match_dual_rules(all_rules, cur_codes, cur_year)

def compute_l3_dynamic_kill(data, cur_codes, cur_year):
    stats = defaultdict(lambda: {'total': 0, 'hit': 0})
    for i in range(len(data) - 1):
        curr, nxt = data[i], data[i+1]
        codes = curr.get('openCode','').split(',')
        nxt_codes = nxt.get('openCode','').split(',')
        if len(codes) < 7 or len(nxt_codes) < 7: continue
        cy = int(curr.get('openTime','')[:4]) if curr.get('openTime') else 2026
        nxt_sx = get_shengxiao_by_suima(int(nxt_codes[-1]),
                                        int(nxt.get('openTime','')[:4]) if nxt.get('openTime') else cy)
        for idx, pos in enumerate(POS_NAMES):
            ping_num = int(codes[idx])
            ping_sx = get_shengxiao_by_suima(ping_num, cy)
            for offset in range(1, 12):
                for dr, sign in [('+', 1), ('-', -1)]:
                    new_num = ping_num + sign * offset
                    if new_num > 49: new_num -= 49
                    elif new_num < 1: new_num += 49
                    new_sx = get_shengxiao_by_suima(new_num, cy)
                    key = (pos, dr, offset, ping_sx, new_sx)
                    stats[key]['total'] += 1
                    if new_sx != nxt_sx:
                        stats[key]['hit'] += 1
    rules = []
    for (pos, dr, offset, ping_sx, killed_sx), v in stats.items():
        if v['total'] >= 63:
            rules.append({
                '位置': pos, '偏移': f'{dr}{offset}', '平码生肖': ping_sx,
                '所得生肖': killed_sx, '样本量': v['total'],
                '命中率': round(v['hit'] / v['total'] * 100, 2)
            })
    if not rules:
        return None
    best = None
    for idx, pos in enumerate(POS_NAMES):
        ping_sx = get_shengxiao_by_suima(int(cur_codes[idx]), cur_year)
        for r in rules:
            if r['位置'] == pos and r['平码生肖'] == ping_sx:
                if not best or r['命中率'] > best['命中率'] or (r['命中率'] == best['命中率'] and r['样本量'] > best['样本量']):
                    best = r
    return best

def get_suima_by_shengxiao(shengxiao, year):
    """根据生肖获取所有岁码（号码）（自动根据年份转换）"""
    benming = get_benming(year)
    benming_idx = SHENGXIAO.index(benming)
    target_idx = SHENGXIAO.index(shengxiao)
    offset = (benming_idx - target_idx) % 12
    base = offset + 1
    numbers = [base, base + 12, base + 24, base + 36]
    return [n if n <= 49 else n - 48 for n in numbers]

    idx = SHENGXIAO.index(shengxiao)

    return SHENGXIAO[new_idx]

def scan_position(records, pos, min_samples=63):
    """扫描单个位置，使用shx_suishu模块"""

    # 全局：每个偏移的命中率
    offset_stats = defaultdict(lambda: {"kill": 0, "total": 0})
    # 双条件：每个(偏移, 生肖)的命中率
    detail_stats = defaultdict(lambda: {"kill": 0, "total": 0, "result_sx": None})

        nxt_year = records[i + 1]["year"]

        nxt_sx = get_shengxiao_by_suima(records[i + 1]["te_num"], nxt_year)

            for sign in [1, -1]:
                new_num = offset_num(num, sign * offset)
                result_sx = get_shengxiao_by_suima(new_num, year)

                offset_stats[off_key]["total"] += 1
                if nxt_sx != result_sx:
                    offset_stats[off_key]["kill"] += 1

                key = (off_key, sx)
                detail_stats[key]["total"] += 1
                detail_stats[key]["result_sx"] = result_sx
                if nxt_sx != result_sx:

    best_offset = None

    best_global_total = 0

            rate = data["kill"] / data["total"] * 100
            if rate > best_global_rate or (rate == best_global_rate and data["total"] > best_global_total):

                }
